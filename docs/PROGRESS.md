### 2026-11-26 — CP-5.2 locations and unique-content gate

- **Collection:** `src/collections/Locations.ts` implements `docs/DATABASE.md §2`: `name`, `slug`, `type` (city/area), `parent`, `intro`, `localNotes` (400–1,500), neighbourhoods, common pests, `servicesAvailable`, local FAQs, `nearbyAreas`, optional `geo` and SEO. Drafts, scheduled publish, trash, Editor/Super Admin writes, public reads only when published, publish/unpublish audit and cache invalidation. A city cannot have a parent and an area must have an existing city parent — enforced on every save, drafts included, because a wrong parent would produce a wrong URL.
- **Publish gate:** drafts stay unrestricted (list minimums are 0) so staff can save work in progress. Publishing requires 400+ characters of local notes, 3 neighbourhoods, 2 common pests, at least one available service and 3 FAQs; the error names every missing item.
- **Similarity:** `src/cms/similarity.ts` normalises copy into three-word shingles and scores the Jaccard overlap against siblings (other cities, or other areas in the same city). 60%+ writes `similarityWarning` (read-only sidebar text), 80%+ refuses the publish. Thresholds are publish rules only, so a near-duplicate draft can still be saved.
